# KirtiBuildWell

Monorepo for KirtiBuildWell — real estate SaaS platform.

Structure:
- `frontend/` — Next.js (App Router), Tailwind, ShadCN UI
- `backend/` — Express.js, MongoDB (Mongoose), Zoho CRM stub

Run locally:

Frontend:
```
cd frontend
npm install
npm run dev
```

Backend:
```
cd backend
npm install
npm run dev
```
